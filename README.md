# collect-tool

## 목적

- 업무에서 종종 다수로부터 진행상황 등 체크를 위해 취합을 받을 때가 있는데, 이런 취합업무 과정 편의를 위한 협업 툴

## 개요

- 역할

> - 슈퍼관리자는 취합을 진행하는 "department" 와 부서관리자 "admin" id 와 초기 비밀번호를 부여하여, 특정 부서의 취합을 위한 db 공간 생성
> - 부서관리자는 실제 취합업무를 수행하는 "취합자" 의 초기 id 및 비밀번호를 부여하며, 취합 항목을 생성, 전체 취합 현황을 실시간으로 조회
> - 취합자는 본인에게 해당하는 취합 항목만 조회 및 수정 가능

- 방법

> - 부서관리자/취합자 모두 동일한 엑셀을 통해 취합 업무 수행, 엑셀에는 "department", "user id", "user name", "user password" 입력하는 셀과, 부서관리자 및 취합자를 조회/생성하는 "USER" 버튼, 취합 항목과 진행상황을 조회/생성할 수 있는 "STATUS" 버튼 존재
> - 부서관리자/취합자든 같은 방식으로 취합 툴 이용할 수 있으나, 부서관리자는 "USER" 버튼을 통해 관리자 비밀번호 변경 및 취합자의 id/이름/초기 비밀번호 세팅 가능하고, "STATUS" 버튼 통해 취합 항목 및 항목들의 초기값 지정 가능
> - 취합자는 본인의 비밀번호와, 본인에게 지정된 취합항목들의 값들만 변경 가능

## 개발

- 기술 스택

> - 엑셀 VBA + supabase

- db 구조

> - "id": int8, "key": jsonb, "value": text[] 컬럼 설정
> - - "key" 는 department: text, table: "user" | "status", userid: text, row: int4 의 프라퍼티 설정, 각각 "부서", "자료종류", "사번", "엑셀 행 위치" 를 나타냄
> - - "value" 는 엑셀 row 행 위치의 가장 왼쪽열부터의 값 순서
